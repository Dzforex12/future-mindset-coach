# Future Mindset Coach Desktop

This is an isolated Electron shell for Windows. It does not modify or bundle
the Next.js web app.

## Run on Windows

From this directory:

```powershell
npm install
npm start
```

The app opens a normal desktop window. Its primary button opens the fixed
Future Mindset Coach Production URL in the system browser.

Voice, wake-word, and computer-action cards are placeholders only. The app
does not access the microphone, start automatically, run hidden, or control
other applications.
